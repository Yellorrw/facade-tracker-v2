# Фасад-трекер В14 — версия 2 (свой сервер)

Трекер выполнения фасадных работ по корпусам К1–К5: кистью закрашиваются реальные панели из DXF, по каждому виду работ свой слой. Закраска хранится на вашем сервере и общая для всех устройств.

## Что изменилось по сравнению с GitHub-версией

| Было | Стало |
|---|---|
| Одна страница 32 МБ, все корпуса сразу | Страница ~40 КБ + геометрия открытого корпуса ~0,5 МБ (сжатая) |
| Синхронизация через Google Apps Script и Google Таблицу | Свой сервер, база SQLite на Mac mini, ежедневные резервные копии |
| Участки КС только в браузере | Участки КС хранятся на сервере (карточка по-прежнему скрыта, как было) |
| — | Панель «Объёмы по осям»: проект по каждой оси журнала, % закрашенного и ≈ выполненный объём |
| — | Необязательный пароль на редактирование |

Режим «только просмотр» остался прежним: на телефонах включается сам, на компьютере — по ссылке `?view=1`.

## Состав папки

```
server.py          сервер (только стандартный Python, ничего ставить не нужно)
import_google.py   перенос накрашенного из старой Google Таблицы
install.sh         установка службы на Mac mini
setup_domain.sh    выход в интернет по домену с HTTPS (Caddy)
static/            сайт: index.html, app.js, style.css, data/corpusN.json.gz и corpusN.ar.bin.gz
move_to_git.sh     разовый переезд службы в папку GitHub Desktop
data/              создаётся при установке: база tracker.db и backups/ (30 последних дней)
logs/              журналы сервера и Caddy
```

## 0. Обновления через GitHub Desktop (разовая настройка)

1. В GitHub Desktop: **File → Clone repository**, выберите `facade-tracker-v2`, в поле **Local path** укажите домашнюю папку (`/Users/ваше-имя`, не Документы и не Рабочий стол — macOS не пустит туда службу). Получится папка `~/facade-tracker-v2`.
2. Один раз в Терминале: `bash ~/facade-tracker-v2/move_to_git.sh` — скрипт остановит старую службу, перенесёт базу закраски и пароль из `~/facade-tracker` и запустит службу из новой папки.
3. Дальше обновления — только кнопкой **Pull origin**.

## 1. Установка на Mac mini

1. Скопируйте папку `facade-tracker` в домашнюю папку Mac mini, например в `~/facade-tracker`.
2. Откройте Терминал и выполните:
   ```
   cd ~/facade-tracker
   chmod +x install.sh setup_domain.sh
   ./install.sh
   ```
   Скрипт спросит пароль на редактирование (можно оставить пустым), попросит пароль администратора Mac, поставит сервер службой (стартует сам при включении, без входа в систему), отключит сон и предложит сразу перенести данные из Google Таблицы.
3. В конце он покажет адрес в домашней сети, например `http://192.168.1.50:8080`. Откройте его с любого устройства дома.

Если Терминал попросит установить «Command Line Tools» — согласитесь, это даёт Python.

## 2. Домен и доступ из интернета

> Cloudflare (в том числе Cloudflare Tunnel) не подходит: с июня 2025 года российские провайдеры ограничивают трафик к сайтам за Cloudflare до 16 КБ, а один корпус весит ~0,5 МБ. Ниже — вариант с российским IP-адресом.

1. **Купите домен** у российского регистратора — например, reg.ru или nic.ru. Зона `.ru` стоит порядка нескольких сотен рублей в год.
2. **Белый (статический) IP.** Закажите у домашнего провайдера услугу «статический / белый IP-адрес» — обычно это недорогая ежемесячная опция. Проверить, белый ли IP уже сейчас: адрес на 2ip.ru должен совпадать с WAN-адресом в настройках роутера.
3. **A-запись.** В DNS домена у регистратора создайте A-запись `@` → ваш белый IP.
4. **Проброс портов на роутере.** Внешние порты 80 и 443 → внутренний IP Mac mini, те же порты 80 и 443. В настройках роутера закрепите за Mac mini постоянный внутренний IP (DHCP-резервирование).
5. **HTTPS.** На Mac mini выполните `./setup_domain.sh ваш-домен.ru`. Скрипт поставит Caddy, тот сам получит бесплатный сертификат Let's Encrypt и будет его продлевать.

Если провайдер не даёт белый IP: возьмите недорогой российский VPS, поставьте Caddy туда и пробросьте на Mac mini туннель (WireGuard или `ssh -R`). Схема та же, меняется только машина с Caddy.

## 3. Переезд со старого сайта

1. Установите и проверьте новый сайт (данные из Google переносит `install.sh`).
2. В день переезда попросите всех перестать красить на старом сайте и выполните на Mac mini:
   `python3 import_google.py --force` — это заново подтянет всё из Google (с последними мазками), а нарисованное уже на новом сайте сохранится.
3. Раздайте новую ссылку. Старый сайт на GitHub Pages можно отключить в настройках репозитория (Settings → Pages).

## Полезное

- **Ссылка только для просмотра** (руководству, заказчику): `https://ваш-домен.ru/?view=1`.
- **Резервные копии:** `data/backups/tracker_ГГГГ-ММ-ДД.db`, по одной в день, хранятся 30 последних. Для восстановления остановите службу и скопируйте нужный файл поверх `data/tracker.db`.
- **Сменить пароль:** поправьте `EDIT_TOKEN` в файле `.env` и выполните `./install.sh` ещё раз (данные не затрагиваются).
- **Обновить сайт:** в GitHub Desktop нажмите **Fetch origin**, затем **Pull origin**. Сайт обновится сразу; если изменился `server.py`, сервер сам перезапустится за несколько секунд. База в `data/` и пароль в `.env` в репозиторий не входят и при обновлении не трогаются.
- **Журнал сервера:** `logs/server.log`.

## Как считается панель «Объёмы по осям»

- Каждая панель чертежа относится к фасаду журнала («1/1-1/4», «5/1-8/1» и т.д.) по своему центру. Фасады выделены на чертежах вручную по осям под каждым видом.
- **Проект** — объёмы из расчёта по исполнительным схемам от 13.10.26: кронштейны, утеплитель 1 и 2 слой, направляющие, пожарная отсечка (L×2), откосы, отливы.
- **%** — доля закрашенной площади панелей фасада по выбранному виду работ.
- **≈ Выполнено** = проект × %.
- Для облицовки (АКП, СФБ, керамогранит, терракота) проект не считался, поэтому показана площадь панелей по чертежу и сколько из неё закрашено, м².
- Подложка — чертёж «Архитектурных решений» по корпусу (`static/data/corpusN.ar.bin`): цвета слоёв, заливки и штриховки как в проекте, ЖБ и кладка, окна. Скрыты слои подсистемы НВФ (Kaft-*, -Д1-*), размеры, тексты, планы, ситуационная схема и всё вне полосы фасадов (спецификации, балконы, другие листы).
- Виды, террасы и кровля видны и красятся; в таблицу по осям они не входят — их % показан строкой под таблицей.
- На вкладке вида работ его слой подсвечен своим цветом (АКП — голубым, СФБ — оранжевым, керамогранит — зелёным, кронштейны — синим, направляющие — пурпурным, утеплитель — жёлтым), чертёж АР при этом приглушён. Выполненное — красная штриховка (предъявляемый участок).
- **К4, фасад 4.4–15.4 по оси Г'.4.** На чертеже он разделён на «4/4-8/4» и «9/4-15/4» между осями 8/4 и 9/4, а участок за осью 15/4 отнесён к «Г/4-А/4».
